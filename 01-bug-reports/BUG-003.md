# BUG-003 · New car spawns inside the previous one and the game freezes

[← Back to bug reports](README.md)

| Field | Value |
|---|---|
| **Game** | CindyCar.Drive |
| **Build** | v0.41 |
| **Device** | Samsung Galaxy S23 (SM-S911B/DS), Android 16 |
| **Severity** | Critical |
| **Priority** | Urgent |
| **Reproducibility** | 5/5 |
| **Labels** | behaviour, physics |

## Steps to reproduce

1. Launch the game
2. Enter sandbox mode on any map
3. Spawn any car
4. Spawn another car

## Actual result

The second car spawns inside the first one, they collide, and the game freezes.

## Expected result

The first car disappears and the second one spawns in its place.
