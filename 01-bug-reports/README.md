## Severity and priority

| Severity | Meaning |
|---|---|
| **Critical / Blocker** | Crash, data or progress loss, the game can't be played |
| **Major** | A main feature is broken, there is a workaround |
| **Moderate** | A feature works wrong, small impact |
| **Minor** | Small visual or text issue |
| **Trivial** | Cosmetic, almost invisible |

**Priority** (Urgent / High / Medium / Low) shows how soon it must be fixed: how many players are affected and how often the bug reproduces.
