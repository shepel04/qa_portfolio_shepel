# BUG-004 · Game does not pause when an alarm/timer goes off during a battle

[← Back to bug reports](README.md)

| Field | Value |
|---|---|
| **Game** | Tank Busters (com.tank.busters) |
| **Build** | 1.0.7 (101) |
| **Device** | Samsung Galaxy S23 (SM-S911B), Android 16 |
| **Severity** | Moderate |
| **Priority** | Medium |
| **Reproducibility** | 1/1 |
| **Found by** | [Interruption checklist](../02-checklists/interruptions-tank-busters/), TC-8 |

## Steps to reproduce

1. Launch the game
2. Start a battle
3. Set a 10 second system timer in the Clock app, or over adb:
   `adb shell am start -a android.intent.action.SET_TIMER --ei android.intent.extra.alarm.LENGTH 10 --ez android.intent.extra.alarm.SKIP_UI true`
4. Return to the battle and wait for the timer to go off
5. Dismiss the timer

## Actual result

The game does not enter pause mode while the timer is ringing. After the timer is dismissed,
the battle continues without a pause menu.

## Expected result

The game pauses when the alarm/timer goes off and resumes in the same state after it is dismissed.
